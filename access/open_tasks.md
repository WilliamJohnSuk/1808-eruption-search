# Open tasks: one list for the whole project

Started 2 Nov 2026 at William's request ("do we keep such checks on record?"; "sure that might be helpful"). It answers one question: **what is still to be done, and who has to do it?**

- **Done checks** stay where they always were: one row per check in `source_register.md` (searched what, when, how read, result), with the detail in the strand's notes file.
- **Items that need human hands** (downloads, Safari, library, archives, researchers) stay in `unavailable_sources.md` with their U-numbers. This file only points to the most useful ones.
- **This file** holds the work that is offered but not yet done: free checks Claude can run, decisions the project owes (put to a Discussion), and old leads still to reconcile.

**Rules for every thread:**
1. When you offer a free check or leave one undone, add it here in the same turn (next free T-number, see foot). Also write it in the strand notes' "Next steps".
2. When a task is done, change its status to `done <date>, <register ref>`. When a task is dropped or superseded, change its status and give the reason. Never delete a row.
3. Statuses: `open (free)`, `open (project decision: Discussion)`, `open (needs hands, U-number)`, `open (maintainer: repo settings)`, `in progress`, `done`, `dropped`, `superseded`.

Verification levels as elsewhere: [page image], [text], [calc], [memory], [suggestion].
