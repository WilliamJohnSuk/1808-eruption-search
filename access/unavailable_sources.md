# Register of sources Claude cannot reach (offline, paywalled, or needing human hands)

Started 27 Oct 2026. Living register, kept alongside `source_register.md`. Every entry was checked against the register section or notes file named in the "Ref" column on 27 Oct 2026 (not from memory). Yield ratings are Claude's judgement (suggestions).

## Standing rule (William, 27 Oct 2026)
Any thread that meets a potentially useful source it cannot read in full, because the source is offline, paywalled, blocked, or needs human hands, **adds it here in the same turn**, as well as recording it in `source_register.md`. When an item is obtained or read, change its status (do not delete the row) and add the date and the register section that holds the result.

## How to add an entry
1. Re-read this file just before editing (other threads write to it). Make small edits.
2. Take the next free number in the series U1, U2, ... (numbers never reused; see "Next free number" at the foot of the file).
3. Put the row in the section for the route it needs (A to E). If it needs two routes, use the cheapest one and say the other in "Route".
4. Fill every column. Status must be one of the terms below, exactly as written.
5. Update "Next free number".

## Status vocabulary (use exactly these terms)
| Status | Meaning |
|---|---|
| **needs Mac download** | Free online; Claude's container is blocked but a curl/script or simple click on William's Mac gets it |
| **needs Safari or captcha** | Free online but needs a real browser: captcha, signed link, bot wall, JS viewer, or Google Books/HathiTrust button |
| **paywalled, not downloaded** | Publisher paywall; Le Moyne access or ILL probably reaches it |
| **library or ILL** | Print only, a thesis, or a subscription database used at a library (Le Moyne, Syracuse) |
| **archives only (on site)** | Manuscript or unique copy, not digitised; must be read in the reading room or by paid copying |
| **requires online request** | Can be had by filling in a request: copy order, permission, API key, account |
| **held by researcher** | Unpublished data; only the authors have it. Whether and how to contact anyone is a project decision (a Discussion, see GOVERNANCE.md); no letter is sent before that |
| **downloaded, not read** | On William's Mac but not yet read by a thread |
| **downloaded and read** | Done; result in the register section given |
| **superseded** | No longer needed (answered by another source, or out of scope); reason given |

Yield: **H** = could locate or date the eruption directly or change a main conclusion; **M** = fills a known gap or tests a specific claim; **L** = completeness or background.
