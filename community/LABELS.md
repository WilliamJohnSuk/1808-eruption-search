# Labels

Created from `community/labels.json` by `scripts/create_labels.sh` (needs the GitHub CLI). Issue forms apply the type and status labels automatically; maintainers add the rest.

| Label | Meaning |
|---|---|
| `ai-generated` | Written or substantially drafted by an AI system; unverified until a person checks it |
| `ai-assisted` | A person used AI help and checked the result against the source |
| `human-verified` | A named person has checked this against the source |
| `page-image` | Read on an image of the original page or manuscript |
| `ocr` | Read from machine-transcribed text only |
| `computed` | Project calculation; script and data in the repo |
| `inferred` | Interpretation, stated as such |
| `source` | A new or updated source |
| `finding` | A reading of a source, positive or negative |
| `negative-result` | Source read; no relevant report found in it |
| `candidate` | About a candidate volcano |
| `retrieval` | Document retrieval (maps to a U-number) |
| `task` | An open task (maps to a T-number) |
| `correction` | Fixes an existing row or note |
| `independent-check` | An independent re-check of an existing source or finding (findings/checks.csv) |
| `hosted-scan` | A page image hosted in sources/scans/ (licence stated; takedown on request) |
| `community` | Repo rules, templates, docs |
| `needs-triage` | Not yet looked at by a maintainer |
| `needs-review` | Ready for checking against the source |
| `needs-hands` | Needs a person at an archive, library, browser or lab |
| `accepted` | Entered the evidence trail |
| `not-accepted` | Reviewed and not entered; reason in the thread |
| `duplicate` | Already in the register or another issue |
| `help-wanted:translation` | Needs a reader of the source language |
| `good-first-task` | Small and self-contained |
