# Scripts for notes/deposition_ratio_validation_2026-10-28.md (28 Oct 2026, register B66)

All outputs are Claude's calculations from downloaded published data (verification level: computed, not page-image checked).

- `run_evah.py`: driver for EVA_H (Aubry et al. 2020, JGR 125, e2019JD031303; Python port by B. Chakraborty, GitHub thomasaubry/EVA_H, cloned 28 Oct 2026). It generates the single-eruption input spreadsheet, integrates the eight-box model and returns the integrated sulfate loss to the troposphere from the SH-extratropical (box 7), tropical (box 5) and NH-extratropical (box 8) boxes, used as a hemispheric deposition proxy, plus monthly SAOD at 550 nm by latitude. The model code is unchanged; one shim makes the removed `scipy.interpolate.interp2d` importable. Needs `pip install scipy netCDF4 pandas openpyxl`; edit the `EVAH` path at the top.
- `grid_evah.py`: 11 latitudes x 4 heights x 3 eruption months x 2 mixing variants (default: no seasonal cycle; optional 20 % seasonal mixing as in the code comments). Output: `data/evah_deposition_ratio_grid_2026-10-28.csv` (the scripts chdir into the EVA_H folder, so their CSVs appear there).
- `timing_evah.py`: SAOD timing for December 1808 scenarios (5°S, 10°N, 10°S; 20, 26, 32 km; 19.3 Tg S) and Tambora/Krakatau comparators. Output: `data/evah_saod_timing_2026-10-28.csv`.
- `validate_emulator.py`: validation of the Marshall et al. 2021 Greenland/Antarctic deposition emulator (GitHub cemac/volcanic-forcing-deposition, files data/axes.json, greenland_{jan,jul}.json, antarctica_{jan,jul}.json) against eruptions of known latitude and month. Observed ratios are typed into the script from fetched text: eVolv2k v2.1 `hemi` (file eVolv2k_v2.1_ds_1.nc in GitHub matthew2e/easy-volcanic-aerosol; Toohey & Sigl 2017, CC BY 4.0), Crowley & Unterman 2013 (NOAA files crowley2013so4-nh.txt and -sh.txt), Sigl et al. 2013 Table 1 (NEEM-2011-S1 / WDC06A), Gao et al. 2007 Table 2. Outputs: `data/deposition_ratio_validation_2026-10-28.csv`, `data/deposition_ratio_of_ratios_vs_tambora_2026-10-28.csv`.
- `data/evolv2k_v2.1_events_2026-10-28.csv`: the 271 eVolv2k v2.1 events (year, month, day, latitude, VSSI, 1-sigma, hemispheric asymmetry NH/SH), dumped from the netCDF; source Toohey & Sigl 2017, licence CC BY 4.0 (WDCC entry).

To rebuild: `git clone https://github.com/cemac/volcanic-forcing-deposition`, `git clone https://github.com/thomasaubry/EVA_H`, `git clone https://github.com/matthew2e/easy-volcanic-aerosol`, then set the paths at the top of each script.
